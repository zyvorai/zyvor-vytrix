VYTRIX · Read-only by design

It watches. It never touches.

A monitor you can leave running on a production box has to be boring about what it can do.

Vytrix does
  • Read processes, ports, resources and containers
  • Group processes by application or .app bundle
  • Require a bearer token and an exact CORS origin
  • Serve HTTPS, and keep the token in tab memory only
  • Keep 30 days of history in a 0600 SQLite file
Vytrix never
  • Kills, signals or renices a process
  • Controls fans, volume or Bluetooth
  • Writes anywhere but its own history file
  • Claims what it did not measure: GPU, sensors and per-app network are absent, and app memory is RSS
  • Shows real data labeled as a demo, or the reverse

The dashboard has no login of its own: put it behind your own access control. See SECURITY.md.
