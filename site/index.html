Built for the questions you actually ask

Which app is it?

Processes grouped by executable or .app bundle, with CPU and memory per application and a process sheet one click away.

Which container?

Docker and Podman side by side: state, CPU, memory against its limit, network I/O and published ports, from read-only CLI calls.

What is on port 5173?

Listening ports tied to the application and its project folder, so a stray dev server is easy to find.

Tell me when

Threshold alerts on CPU, memory, disk and containers, with a level you set. No notifications you did not ask for.

What happened earlier?

Activity history in the tab, and 30 days of samples in a 0600 SQLite file that the collector serves over an authenticated API.

Safe to leave running

Bearer token, exact CORS origin, HTTPS. No mutations in the API: it cannot do anything to the machine.

Native on the Mac

A SwiftUI app with the collector bundled: a menu bar item (CPU, host totals, alert count, busiest apps), local notifications once per alert, a System widget and two Shortcuts actions. Read-only like everything else. Built and run on macOS 27.2; not checked on macOS 26, and the widget has not been seen in the widget gallery (docs/WIDGETS.md).

  • Menu barClosing the window keeps Vytrix in the menu bar; Quit stops it and its collector.
  • NotificationsYour alert rules, once per alert, never for demo data.
  • Widget and Shortcuts"What is using my CPU?" and "How is my Mac doing?" answer from the app's last reading.
  • Time MachineScrub up to 1000 stored samples (about 33 minutes at the default interval). Needs a collector.

What happened, and why

History lives in a 0600 SQLite file next to the collector, and everything below is computed from it on request. Demo data and imported snapshots have no history, so they show none of this.

Time Machine

A scrubber replays the collector's stored samples: tiles, apps, containers, ports and alerts show the sample at that time, and Back to Live returns.

v0.6.0 notes

Anomaly bands and evidence

Ranges that break an exponentially weighted band are shaded on CPU, memory, disk and network. Drag across a range to see what was busy in it against the range before.

Collector API

Incident timeline

Alert transitions, container changes and anomaly windows in one ordered list, with a short fingerprint of the pattern and why the window differs from the one before. Deterministic, no model.

Collector API

For your assistant: MCP

A read-only MCP server over a running collector. Every tool is one GET, and a test asserts that none writes anything.

docs/MCP.md

Several Macs experimental

Optional. A small worker on each Mac pushes its snapshot to a coordinator; the dashboard reads the coordinator. No command channel. Checked with one real Mac over loopback, not yet across two Macs or over HTTPS.

docs/CLUSTER.md

Fleet Pro new, opt-in

Central history, metadata, roles, alerts and exports on top of the read-only collector. It adds no command channel, and counters a host does not expose are omitted, not estimated. Not yet checked across several Macs or over HTTPS.

docs/FLEET-PRO.md

A browser, a collector, your machine

A web page cannot read your processes, so a small collector does, read-only, and the dashboard polls it over HTTPS. Without one, the dashboard shows clearly labeled simulated telemetry.

Quickstart

Node 22.13 or newer. npx pnpm@11.25.0 … works without installing pnpm.

git clone https://github.com/zyvorai/zyvor-vytrix.git && cd zyvor-vytrix
npx pnpm@11.25.0 install --frozen-lockfile
npx pnpm@11.25.0 dev            # http://localhost:5173, simulated telemetry

Your own readings, offline (Python 3.10+, no root), then Connect → Import collector snapshot:

python3 agent/vytrix.py --once > snapshot.json

Live telemetry from a collector on this machine:

export VYTRIX_TOKEN="$(python3 -c 'import secrets; print(secrets.token_urlsafe(32))')"
python3 agent/vytrix.py --allow-origin http://localhost:5173

For an MCP client, a read-only server is listed in the MCP Registry as io.github.zyvorai/vytrix once the v0.8.0 release publishes it. It is a stdio container image, ghcr.io/zyvorai/vytrix-mcp:0.8.0, with six read-only tools (plus optional cluster tools, four prompts and two resources); set VYTRIX_URL and VYTRIX_TOKEN (secret). See docs/MCP.md.

One command to a Linux server

./scripts/deploy-remote.sh 203.0.113.10 deploy      # HOST USER, or user@host

It syncs the checkout over SSH, builds it on the host, and installs two systemd units: the dashboard on loopback and the collector on https://HOST:30847 with a self-signed certificate, proxying the dashboard. Open the URL, accept the certificate, Connect, and paste the token. For a Mac or a laptop, scripts/install-macos.sh (launchd, token in the Keychain) and scripts/install-linux.sh (systemd) install the collector as a service.

The dashboard has no login of its own: put it behind your own access control. What the collector token protects, and what it does not, is in SECURITY.md.
